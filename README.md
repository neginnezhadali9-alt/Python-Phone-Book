# Python Phone Book
A simple Phone Book application built with Python.

## Features
-Add new contact
-Show all saved contacts 
-Search for a contacts
-Delete existing contact
-Exit the program

## Techologies
-Python 3 

## python Concepts Used
-Variables
-Dictionnaries
-While Loops
-For Loops
-Conditional Statements (if / elif / else)
-Nested Conditions
-User Input and Output 
-Comparison operators
-Dictionary Methods (.items())
-Dictionary Item Assignment
-Delete Statement (del)
-Break Statement

## How to Run
Run the following command: python main.py
